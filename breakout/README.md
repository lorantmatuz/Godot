# Breakout

A small brick-breaker.

## Running

Open `project.godot` in Godot 4.7 or newer and press F5.

## Controls

- A/D or Left/Right — move the paddle
- Space — launch the ball
- R — restart

## Tests

Headless smoke test. From the repository root:

```sh
godot --headless --path breakout --script res://tests/smoke_test.gd
```
