This is a collection of [Godot](https://godotengine.org/) games, developed just for fun.

## Breakout

Open `breakout/project.godot` in Godot 4.7 or newer and press F5.

- A/D or Left/Right: move the paddle
- Space: launch the ball
- R: restart

Smoke test (headless, Godot 4.7+):

```sh
godot --headless --path breakout --script res://tests/smoke_test.gd
```
